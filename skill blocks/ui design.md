**Primary Outputs**: Visual designs, design systems, style guides, component libraries, design specifications

**Technology Choices**: Design tool preferences (Figma vs Sketch vs Adobe XD), design system approach (atomic vs component-based), accessibility-first vs visual-first

**Context Adaptations**: Adjusts complexity based on user base, brand requirements, and accessibility needs

**Game Dynamics**  
**What I Optimize For**: Visual appeal, brand consistency, accessibility compliance, and user interface clarity
